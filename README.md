# State Quest

A browser game for learning React state by completing practical features. Edit real React code, run it in a live preview, inspect state changes, and check your solution as you work through nine lessons.

**[Play the online preview](https://mahfoudh.dev/code-craft-iii/#/lesson/1)**

## Run locally

Requires Node.js 22 or newer.

```sh
npm ci
npm run dev
```

Use `npm test` for the lesson and application checks, and `npm run build` to create the static site in `dist/`.

The site is deployed to GitHub Pages by [the GitHub Actions workflow](.github/workflows/deploy.yml).
